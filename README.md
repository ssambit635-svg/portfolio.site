# Sambit Swain — Portfolio

> A motion-first, cream-toned designer portfolio. GSAP scroll choreography, real glTF clay models in WebGL, and a CI/CD pipeline that ships every push straight to GitHub Pages.

## 🌐 Live

https://ssambit635-svg.github.io/portfolio.site/

---

## ✨ What makes it different

**It is designed, not assembled.** One palette, one type pairing, one grid — and a lot of restraint. Cream paper surfaces, warm ink type, a serif italic accent, film grain over everything, and motion that supports the story instead of shouting over it.

| Layer | Details |
| --- | --- |
| **Scroll narrative** | GSAP `ScrollTrigger` pins the hero and the work section; the project rail travels sideways with per-card reveals driven by `containerAnimation` |
| **Real 3D** | Four `.glb` models (blob, knot, crystal, column) generated by `scripts/build-models.mjs`, rendered with react-three-fiber and shaded with physical materials — transmission for the gem, clay sheen for the pebble |
| **Interaction** | Magnetic buttons, pointer-tracking spotlight cards, draggable gem, cursor-following certificate previews, velocity-reactive marquee |
| **Typographic motion** | `SplitText` line masking — headlines rise out of clipped lines with editorial easing |
| **Craft details** | Custom cursor with contextual labels, live IST clock, scroll progress hairline, copy-to-clipboard email, film grain + paper texture |

Motion is opt-out friendly: `prefers-reduced-motion` and touch devices get the native scroll, no custom cursor, and static fallbacks everywhere.

## 🗂 Structure

```
portfolio.site/
├── .github/workflows/deploy.yml   # typecheck → build → deploy to Pages
├── public/                        # robots.txt, sitemap.xml
├── scripts/
│   ├── build-models.mjs           # generates src/assets/models/*.glb
│   ├── verify-models.mjs          # parses each .glb back and reports tri counts
│   └── smoke.mjs                  # headless render check (jsdom + esbuild)
├── src/
│   ├── components/
│   │   ├── layout/                # Preloader, Nav, Footer
│   │   ├── sections/              # Hero, Ticker, Work, About, Skills,
│   │   │                          # Certificates, Process, Contact
│   │   ├── ui/                    # RevealHeading, Magnetic, SpotlightCard,
│   │   │                          # Marquee, Counter, Cursor, ScrollProgress
│   │   └── work/ProjectCard.tsx
│   ├── hooks/                     # media query, in-view, timezone clock
│   ├── lib/                       # site copy, GSAP setup, utils
│   ├── providers/SmoothScroll     # Lenis + ScrollTrigger sync
│   ├── three/                     # SceneCanvas, HeroBlob, ClayKnot,
│   │                              # CrystalGem, ClayPillar, pointer
│   ├── assets/models/             # hand-generated .glb files
│   └── assets/certs/              # certificate scans
├── Dockerfile · nginx.conf
└── index.html
```

## 🚀 Commands

```bash
npm install          # install dependencies
npm run dev          # dev server → http://localhost:5173
npm run build        # typecheck + production build into dist/
npm run preview      # serve the production build locally
npm run typecheck    # tsc --noEmit
npm run models       # regenerate + verify the 3D models
node scripts/smoke.mjs   # headless render smoke test
```

### Docker

```bash
docker build -t sambit-portfolio .
docker run -p 8080:80 sambit-portfolio
# → http://localhost:8080
```

## ⚙️ Pipeline

1. Push to `main`
2. GitHub Actions installs, type-checks and builds (`dist/`)
3. The artifact is deployed to GitHub Pages

`vite.config.ts` uses a relative `base`, so the same build works on a Pages project URL, a custom domain, or inside the Docker image.

## 🛠 Stack

**Frontend** React 19 · TypeScript · Vite · Tailwind CSS v4
**Motion** GSAP 3 (ScrollTrigger, SplitText, CustomEase) · Lenis
**3D** three.js · @react-three/fiber · @react-three/drei
**Type** Inter Tight · Instrument Serif · JetBrains Mono (self-hosted)
**Ops** GitHub Actions · GitHub Pages · Docker · Nginx
